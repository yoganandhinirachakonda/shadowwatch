# ShadowWatch - AI That Stops Crime Before It Happens

ShadowWatch is an AI safety platform that predicts crime before it happens.

## Features
- Live Crime Heatmap - Red = High Risk, Yellow = Caution, Green = Safe
- Police Dashboard - AI predicts Top 5 Risk Zones for tonight
- Safe Route Finder - Shows safest route in green, dangerous in red
- SOS Emergency Button - Sends live location to police + family
